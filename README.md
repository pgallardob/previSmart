# PreviSmart — individual advisory software

[Open the app on a phone](https://pgallardob.github.io/previSmart/) · [Download the complete Windows package](https://github.com/pgallardob/previSmart/releases/latest/download/PreviSmart-Windows.zip) · [Download the web package](https://github.com/pgallardob/previSmart/releases/latest/download/PreviSmart-web.zip) · [Latest release and file checksums](https://github.com/pgallardob/previSmart/releases/latest)

Android: open the app in Chrome and choose Install app / Add to Home screen. iPhone: open in Safari and choose Share → Add to Home Screen. A downloaded web ZIP is not a phone installer. Windows: extract the complete PreviSmart folder and open PreviSmart.exe; keep all included folders together.

Updates: reopen the app online and confirm Update app when offered. Do not uninstall or clear browser data to update. Each installation keeps its own local clients and documents; there is no portfolio synchronization. See [installation instructions](site/docs/INSTALACION_INDIVIDUAL.md).

## Distribution boundaries

Publish only `site/` with GitHub Pages Actions. This repository contains software only: never add client files, credentials, browser data or development history. Windows releases attach a separately verified portable package. No client-server backend is included.

Review GitHub Pages usage restrictions before publication; do not use it for commercial SaaS or sensitive network transactions. The Pages workflow is manually triggered.
