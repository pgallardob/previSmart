# PreviSmart — static distribution

Publish only `site/` with GitHub Pages Actions. The workflow is manually triggered. This repository must contain software only: never add client files, credentials, browser data or the development repository history. No client-server backend is included. Client records remain in each installation.

Review GitHub Pages usage restrictions before publication; do not use it for commercial SaaS or sensitive network transactions. Configure Settings → Pages → Source: GitHub Actions, then run the publication workflow.
